Primera versión de Havi Hub, un launcher libre y de código abierto para Minecraft Java Edition, para Windows y Linux. Usa [Prism Launcher](https://prismlauncher.org) como motor de juego y permite buscar e instalar mods y modpacks de CurseForge y Modrinth sin salir de la aplicación.

### Qué archivo descargar

| Sistema | Archivo |
|---|---|
| Windows 10 y 11 | `HaviHub-1.0.0-Setup.exe`, el instalador (recomendado) |
| Windows, sin instalar | `HaviHub-1.0.0-portable.exe` o `HaviHub-1.0.0-win-x64.zip` |
| Linux, cualquier distribución | `HaviHub-1.0.0-linux-x86_64.AppImage` |
| Debian, Ubuntu y derivadas | `HaviHub-1.0.0-linux-amd64.deb` |

- Los archivos de Windows todavía no tienen firma digital, así que la primera vez Windows puede mostrar «Windows protegió su PC». Para abrirlo, presiona **Más información** y después **Ejecutar de todas formas**.
- El AppImage necesita FUSE 2. Si no abre, en Ubuntu 24.04 instala `libfuse2t64`, y en Ubuntu 22.04 o Debian, `libfuse2`. La guía de uso tiene el comando para otras distribuciones.
- Para jugar se necesita una cuenta de Microsoft que tenga Minecraft Java Edition. La primera vez, Havi Hub descarga su motor de juego (unos 45 MB).

### Qué incluye

- Dos diseños a elección, uno parecido a la app de CurseForge y otro a la de Modrinth, con las mismas funciones. Se puede cambiar en cualquier momento en Ajustes → Temas.
- Mods, modpacks, resource packs, shaders, data packs y mundos de CurseForge y Modrinth, con sus dependencias y actualizaciones. Cada mod se puede cambiar a otra versión, y al actualizar se elige qué actualizar.
- Importación de perfiles desde CurseForge, Modrinth y Prism Launcher, con sus ajustes de inicio (memoria, Java, argumentos, variables de entorno y comandos). Los perfiles también se pueden mantener sincronizados con Prism Launcher y con las apps de CurseForge y Modrinth, desde una sola ventana.
- Ajustes generales y por perfil: Java, memoria, argumentos, variables de entorno, comandos de inicio y librerías nativas, además de las teclas y las opciones del juego con que empiezan los perfiles nuevos.
- Si el juego se cierra por un error o no logra iniciar, Havi Hub vuelve al frente y muestra el registro del perfil.
- Visor de skins en 3D con las skins por defecto del juego, buscador de servidores (los más conocidos junto a la lista de Modrinth), galería de capturas, temas (también de temporada) y cuentas offline.
- Interfaz en español y en inglés.
- Sin anuncios ni telemetría. Los servicios a los que se conecta la app están en la [política de privacidad](https://havihub.github.io/privacy/).

### Ayuda

- La [guía de uso](https://github.com/havihub/HaviHub/blob/main/LEEME.md) explica cada función y tiene una sección de preguntas frecuentes.
- Si algo no funciona, puedes [reportarlo aquí](https://github.com/havihub/HaviHub/issues/new/choose). Si el problema es con el juego, el log del perfil se sube con un botón y basta con pegar el enlace en el reporte.
- Si Havi Hub te sirve y quieres apoyarlo, puedes hacer una donación en [Ko-fi](https://ko-fi.com/havikunn).

## English

This is the first release of Havi Hub, a free and open-source launcher for Minecraft Java Edition, for Windows and Linux. It uses [Prism Launcher](https://prismlauncher.org) as its game engine and lets you find and install mods and modpacks from CurseForge and Modrinth without leaving the app.

### Which file to download

| System | File |
|---|---|
| Windows 10 and 11 | `HaviHub-1.0.0-Setup.exe`, the installer (recommended) |
| Windows, without installing | `HaviHub-1.0.0-portable.exe` or `HaviHub-1.0.0-win-x64.zip` |
| Linux, any distribution | `HaviHub-1.0.0-linux-x86_64.AppImage` |
| Debian, Ubuntu and derivatives | `HaviHub-1.0.0-linux-amd64.deb` |

- The Windows files are not code-signed yet, so the first time Windows may show "Windows protected your PC". To open it, press **More info** and then **Run anyway**.
- The AppImage needs FUSE 2. If it does not start, install `libfuse2t64` on Ubuntu 24.04, or `libfuse2` on Ubuntu 22.04 and Debian.
- Playing requires a Microsoft account that owns Minecraft Java Edition. On its first start, Havi Hub downloads its game engine (about 45 MB).

### What it includes

- Two layouts to choose from, one similar to the CurseForge app and one similar to the Modrinth app, with the same features. You can switch at any time in Settings → Themes.
- Mods, modpacks, resource packs, shaders, data packs and worlds from CurseForge and Modrinth, with their dependencies and updates. Any mod can be switched to another version, and you choose what gets updated.
- Import of profiles from CurseForge, Modrinth and Prism Launcher, with their launch settings (memory, Java, arguments, environment variables and commands). Profiles can also be kept in sync with Prism Launcher and with the CurseForge and Modrinth apps, all from one window.
- Global and per-profile settings: Java, memory, arguments, environment variables, launch commands and native libraries, plus the key bindings and game options that new profiles start with.
- If the game closes because of an error or fails to start, Havi Hub comes back to the front and shows the profile's log.
- A 3D skin viewer with the game's default skins, a server browser (the best-known servers together with Modrinth's list), a screenshot gallery, themes (seasonal ones too) and offline accounts.
- Interface in Spanish and English.
- No ads and no telemetry. The services the app connects to are listed in the [privacy policy](https://havihub.github.io/privacy/).

### Help

- The [user guide](https://github.com/havihub/HaviHub/blob/main/LEEME.md), written in Spanish, explains every feature and has a section of frequently asked questions.
- If something does not work, you can [report it here](https://github.com/havihub/HaviHub/issues/new/choose). If the problem is with the game, the profile's log can be uploaded with one button, so you only need to paste the link in the report.
- If Havi Hub is useful to you and you would like to support it, you can make a donation on [Ko-fi](https://ko-fi.com/havikunn).
